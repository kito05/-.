# Weather Station on Arduino

## Концепция
Система для сбора данных с датчиков температуры и влажности с передачей на сервер.

## Технологический стек
- Python 3.11, FastAPI, PostgreSQL 15, Docker

## Структура проекта
├── src/ ├── tests/ ├── .env.example └── README.md

## Развертывание
1. Клонируйте репозиторий
2. Скопируйте `.env.example` в `.env`
3. Запустите `docker-compose up --build`
