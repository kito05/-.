# Schedule Manager — Модуль составления и динамического расписания занятий и аудиторий

## Концепция
Система для автоматического и ручного составления расписания занятий с учётом доступности аудиторий, загруженности преподавателей и групп. Поддерживает динамическое обновление при изменениях (замена преподавателя, перенос занятия, отмена пары).

## Технологический стек
- **Язык**: Python 3.11
- **Фреймворк**: FastAPI (бэкенд), React (фронтенд — опционально)
- **СУБД**: PostgreSQL 15
- **Инструменты**: Docker, Docker Compose, SQLAlchemy
- **Планировщик**: OR-Tools (для автоматической оптимизации расписания)
